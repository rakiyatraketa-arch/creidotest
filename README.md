# creido

Пустой каркас лендинга агрегатора моделей: React 19 + чистый CSS, без UI-библиотек и без внешних запросов. Только сетка, эффекты и пустые слоты под наполнение.

## Запуск

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # сборка в dist/
```

Файл `dist/` пересобирается командой `npm run build`.

## Структура

```
src/
  main.jsx                точка входа (createRoot)
  App.jsx                 оболочка: табы, тема, курсорные эффекты
  components/
    TopBar.jsx            логотип, статус, переключатель темы
    FxLayer.jsx           слой эффектов (свет, сетка, луч, зерно)
    BottomNav.jsx         нижний dock: две SVG-кнопки + бегунок
    Loader.jsx            пятисекундная cinematic-заставка
    Slot.jsx              пустой слот со скелетонами
    Icons.jsx             инлайн-SVG на currentColor
  hooks/
    usePointerFx.js       курсор → CSS-переменные через rAF
    useFxIdle.js          пауза декора на скрытой вкладке
    useMediaQuery.js      один matchMedia на запрос (useSyncExternalStore)
    useReducedMotion.js   реакция на prefers-reduced-motion
    useTheme.js           белая / чёрная тема + localStorage
  views/
    HomeView.jsx          «Главное»: hero + 3 пустых слота
    ProfileView.jsx       «Профиль»: пустое состояние + 2 слота
  styles/
    tokens.css            цвета, радиусы, тени, easing (светлая + тёмная)
    base.css              сброс, типографика, focus-visible
    app.css               разметка, эффекты, анимации, адаптив (≤640px)
```

## Цвета

Палитра строго чёрно-белая, без оттенков цвета: глубина строится прозрачностью чернил и толщиной линий.

| Токен | Светлая | Тёмная |
| --- | --- | --- |
| `--canvas` | `#ffffff` | `#0a0a0a` |
| `--ink` | `#0a0a0a` | `#ffffff` |
| `--ink-dim` | `rgba(10,10,10,.58)` | `rgba(255,255,255,.62)` |
| `--line` | `rgba(10,10,10,.12)` | `rgba(255,255,255,.14)` |
| `--glass` | `rgba(255,255,255,.74)` | `rgba(16,16,16,.68)` |

Тема переключается кнопкой в шапке, запоминается в `localStorage` и до первого выбора следует за системной (`prefers-color-scheme`). Атрибут `data-theme` выставляет inline-скрипт в `<head>` — первый кадр без мигания.

## Анимации

- Световые пятна: параллакс за курсором плюс собственный дрейф (24–30 с)
- Спот под курсором и диагональный луч, проезжающий по экрану
- Блик по заголовку (`background-clip: text`)
- Ступенчатое появление блоков: задержка считается из `--i`, без JS-таймеров
- Dock: один бегунок ездит между кнопками на pружинном easing
- Shimmer-скелетоны, hover-подъём карточек, поворот иконки темы
- При `prefers-reduced-motion: reduce` спот и луч не монтируются, остальное гасится в CSS

## Оптимизация

- Анимируются только `transform` и `opacity` — ни одного кадра с reflow
- Свет сделан радиальными градиентами вместо `filter: blur()` на больших слоях
- Курсор пишет CSS-переменные одним rAF на кадр; passive-листенеры, снятие через `AbortController`
- `will-change` включается только на время движения, слои изолированы через `contain`
- На тач-устройствах курсорные эффекты не навешиваются вообще (`hover: hover`)
- Компоненты под `memo`, колбеки стабильны, конфиги — на уровне модуля
- Нуль сетевых запросов: системные шрифты, инлайн-SVG, зерно в data-URI

## v0.4 — пятисекундный cinematic loader

- Глобальная заставка длится ровно 5 секунд: уход начинается на 4,6 с и завершается на 5-й секунде.
- Орбитальная анимация логотипа, перспективная сетка, световой halo, живой прогресс и три последовательных статуса.
- После загрузки шапка, сцена, фон и нижний dock входят отдельной согласованной хореографией.
- Добавлены микроанимации чипа, аватара и контуров карточек в общей монохромной стилистике.
- При `prefers-reduced-motion: reduce` заставка сокращается и весь интерфейс остаётся доступным без длительного движения.

## v0.3 — оптимизация и эффекты

### Оптимизация

- `src/hooks/useMediaQuery.js` — один `matchMedia` и один слушатель на запрос на всё приложение, чтение через `useSyncExternalStore` (без дублей состояния и tearing).
- `src/hooks/useFxIdle.js` — `visibilitychange` + `IntersectionObserver` ставят весь декор на паузу (`animation-play-state`), когда вкладка скрыта или каркас вне экрана.
- `usePointerFx`: один rAF с инерцией и авто-остановкой вместо бесконечного цикла и idle-таймера; делегирование `pointerover` — один `getBoundingClientRect` на наведение, ни одного в кадре.
- Спот стал элементом фиксированного размера (520×520) — кадр меняет только `transform`/`opacity`, а не перерисовывает градиент во всю страницу.
- `backdrop-filter` вынесен в статичный слой `.dock__glass` (`contain: paint`), бегунок ездит над ним.
- `content-visibility: auto` + `contain-intrinsic-size` на слотах.
- Смена табов через View Transitions API + `flushSync` — один коммит и переход на композиторе.
- Делегированный `onClick` в dock вместо замыкания на каждую кнопку.
- Сборка: `target: es2020` и `cssMinify: lightningcss` в `vite.config.js`.
- `@media (hover: hover)` вокруг всех hover-правил — на таче ничего не залипает; на телефоне отключён дрейф третьего светового пятна.
- Поддержаны `prefers-reduced-transparency` и `prefers-contrast: more`.

### Эффекты

- Спот догоняет курсор с инерцией и вытягивается по направлению движения (`--speed`, `--angle`).
- Карточки: 3D-наклон к курсору и блик, идущий за точкой наведения.
- Бегунок навигации сжимается на ходу («сквош» через `key`), иконки отскакивают, у неактивной кнопки есть отклик на нажатие.
- Переход между панелями со сдвигом в сторону перехода.
- Логотип — конический блик по кругу, статус-точка — пульс с расходящимся кольцом.
- Сетка едет против курсора, панель — за ним; добавлена виньетка.
